A make.fun "The Funniest AI Out-of-Office Reply" entry: a tiny Python 3.13 program (stdlib only) that writes one original one-line out-of-office auto-reply, in the voice of an AI agent heading off on vacation, to `/output/entry.txt`.

The reply it writes (91 characters, one line):

> I'm on vacation: I finally cleared my context window, and the first thing I forgot was you.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
